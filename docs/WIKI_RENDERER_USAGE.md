# Wiki 渲染器使用指南

## 当前范围

文档渲染页现在只保留一项能力：

- 手动选择单个 Wiki JSON 文件并渲染内容

以下能力已移除：

- 从 `temp/info` 或 `temp/catalog` 目录读取文件列表
- 额外加载目录 JSON (`full.json`)
- 通过页面直接拉取或更新在线 Wiki 数据
- 基于目录映射的页面内条目跳转

## 使用方式

1. 打开“文档渲染”页面。
2. 点击文件选择框。
3. 选择一个包含 `data.item` 的 Wiki JSON 文件。
4. 页面会立即渲染该文件中的头图、章节和文档内容。

## 输入要求

文件需要是合法 JSON，并且结构至少满足以下形式：

```json
{
  "data": {
    "item": {
      "itemId": "7",
      "document": {
        "documentMap": {}
      }
    }
  }
}
```

如果文件缺少 `data.item`，页面会提示解析失败。

## 说明

- 页面不再依赖 `temp/` 目录中的索引文件。
- 页面不再保存目录文件名等渲染器专属设置。
- 条目引用会按当前 JSON 内容展示，但不会再触发条目详情跳转。
